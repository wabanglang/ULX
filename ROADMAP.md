# ULX Public Roadmap

## Phase 0 — Public provenance

- Publish the ULX concept and public boundary.
- Establish claim labels and benchmark rules.
- Invite falsification and counterexamples.

## Phase 1 — Frozen fixtures

- Publish small, non-sensitive source fixtures.
- Define semantic acceptance criteria before transformation.
- Record size, retention, ambiguity, contradiction, and provenance metrics.

## Phase 2 — Cross-model evaluation

- Run the same public fixtures across multiple AI systems.
- Measure semantic drift and reconstruction variance.
- Publish failures alongside successes.

## Phase 3 — Corpus-scale tests

- Test progressively larger conversations and project corpora.
- Compare raw context, ordinary summarization, structured baselines, and ULX-derived representations.
- Separate storage savings from inference-time or token-efficiency claims.

## Phase 4 — Public tooling boundary

- Release only tooling that can be published without exposing protected private mechanics.
- Prefer deterministic validators, fixture runners, scoring utilities, and conformance tests.

## Phase 5 — Independent replication

- Provide third parties enough material to reproduce public claims.
- Track contradictory findings rather than filtering them out.
- Upgrade `EXPERIMENTAL` findings to `DEMONSTRATED` only when evidence warrants it.

## Long-range question

Can a large human–AI history become a compact, inspectable, portable knowledge object without sacrificing the relationships and uncertainty needed to continue the work faithfully?
